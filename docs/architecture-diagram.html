Authentication Systems

Three completely separate auth flows for three user types — CRM users, KPT Partners, and KPT Admins.

Auth System 1 — CRM Internal Users (ADMIN / SALES)

JWT via Express API · bcrypt · role-based access control
sequenceDiagram actor User as 👤 CRM User participant FE as Next.js Frontend participant API as Express API :4000 participant DB as PostgreSQL Note over User,DB: ── Login ── User->>FE: Enter email + password FE->>API: POST /api/auth/login API->>DB: prisma.user.findUnique({ email }) DB-->>API: User record API->>API: bcrypt.compare(password, passwordHash) API->>API: generateToken(userId, email) → JWT (24h) API-->>FE: { token, user, isDeveloper: false } FE->>FE: Store token in AuthContext Note over User,DB: ── Authenticated Request ── User->>FE: Navigate to /leads FE->>API: GET /api/leads\nAuthorization: Bearer API->>API: requireAuth middleware\nverifyToken(token) API->>DB: prisma.user.findUnique(userId) DB-->>API: User + role API->>API: Attach req.user = {id, email, role} API->>DB: prisma.lead.findMany({...filters}) DB-->>API: Lead records API-->>FE: JSON response FE->>FE: React Query caches + renders Note over User,DB: ── Password Reset (3-step OTP) ── User->>FE: Forgot password FE->>API: POST /api/auth/forgot-password { email } API->>API: Generate 6-digit OTP API->>API: bcrypt.hash(otp) API->>DB: prisma.passwordReset.create(otpHash, expiresAt) API->>API: emailService.sendEmail(otp) via Plunk User->>FE: Enter OTP FE->>API: POST /api/auth/forgot-password/verify { email, otp } API->>DB: Find latest PasswordReset (not used, not expired) API->>API: bcrypt.compare(otp, otpHash) API->>DB: Mark usedAt = now() API->>API: generateResetToken(userId, recordId) → 15min JWT API-->>FE: { resetToken } FE->>API: POST /api/auth/forgot-password/reset { resetToken, newPassword } API->>API: verifyResetToken(resetToken) API->>DB: prisma.$transaction([update password, invalidate all resets]) API->>API: createNotification(PASSWORD_RESET) API-->>FE: { success: true }
